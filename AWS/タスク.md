# タスク

https://tryhackme.com/room/theoversharingcontainer

AWS ECSにおける「タスク（Task）」とは、「実際にサーバー上で動いているコンテナの最小実行単位（グループ）」のこと。Dockerの文脈で例えると、「1台の仮想マシン（またはPod）上でまとめて起動している1つ以上のDockerコンテナ群」を指す。

タスク定義 (TaskDefinition)は、「どのDockerイメージを使うか」「CPUやメモリはいくらにするか」などを書いた設定ファイル。  
タスクは、その設計図をもとに、EC2インスタンス上で実際に動いている実体。

```sh
TASK_DEF_ARN=$(aws ecs describe-services \
  --cluster "$CLUSTER_NAME" \
  --services "$SERVICE_NAME" \
  --query "services[0].taskDefinition" \
  --output text)

aws ecs describe-task-definition \
    --task-definition "$TASK_DEF_ARN" \
    --query "taskDefinition.{Family:family,TaskRole:taskRoleArn,ExecutionRole:executionRoleArn,NetworkMode:networkMode}" \
    --output json

{
    "Family": "room44-app",
    "TaskRole": null,
    "ExecutionRole": "arn:aws:iam::664418977660:role/room44-lab-execution-role",
    "NetworkMode": "bridge"
}
```

TaskRoleArn が null のタスク定義から実行されたコンテナは、ホストの EC2 インスタンスロールにフォールバックできる。  
つまり明示的にロールを割り当てないと、非常に大きな権限が割り当てられる。
