# サブネット

https://tryhackme.com/room/theexposedsubnet

## 列挙

サブネットの列挙

```sh
aws ec2 describe-subnets \
  --filters "Name=vpc-id,Values=$VPC_ID" \
  --query "Subnets[*].{Name:Tags[?Key=='Name']|[0].Value,CIDR:CidrBlock,PublicIP:MapPublicIpOnLaunch,SubnetId:SubnetId}" \
  --output table
```

サブネットに関連付けられたルーティングテーブル

```sh
aws ec2 describe-route-tables \
  --filters "Name=association.subnet-id,Values=$BACKEND_SUBNET" \
  --query "RouteTables[].{Name:Tags[?Key=='Name']|[0].Value,Routes:Routes[].{Dest:DestinationCidrBlock,Target:GatewayId}}" \
  --output json
```

インスタンスに関連付けられているPublicIP

```sh
aws ec2 describe-instances \
  --filters "Name=vpc-id,Values=$VPC_ID" "Name=instance-state-name,Values=running" \
  --query "Reservations[].Instances[].{Name:Tags[?Key=='Name']|[0].Value,PrivateIP:PrivateIpAddress,PublicIP:PublicIpAddress,SubnetId:SubnetId}" \
  --output table
```

## 操作

ルートテーブルの関連付けを置き換える

```sh
aws ec2 replace-route-table-association \
  --association-id $ASSOC_ID \
  --route-table-id $PRIVATE_RT
```

PublicIPの自動割り当てを無効にする

```sh
aws ec2 modify-subnet-attribute \
  --subnet-id $BACKEND_SUBNET \
  --no-map-public-ip-on-launch
```

## NACL

https://tryhackme.com/room/theforgottennacl

NACLはサブネット境界での「大まかな粗いフィルタ（CIDR単位の拒否など）」として使い、細かなポート制御やステートフルな通信制御はセキュリティグループ（SG）側で厳しく制御するという考え方。

サブネットに紐づくACLを表示。紐づくサブネットの数だけ表示される。

```sh
aws ec2 describe-network-acls \
  --filters "Name=vpc-id,Values=$VPC_ID" \
  --query "NetworkAcls[*].{ID:NetworkAclId,IsDefault:IsDefault,Subnets:length(Associations), \
  InboundRules:Entries[?Egress].{Rule:RuleNumber,Action:RuleAction,CIDR:CidrBlock}, \
  OutboundRules:Entries[?Egress].{Rule:RuleNumber,Action:RuleAction,CIDR:CidrBlock}}" \
  --output json
```

上記はどのサブネットに紐づいているかはわからないので、わかるように表示。

```sh
aws ec2 describe-network-acls \
   --filters "Name=vpc-id,Values=$VPC_ID" \
   --query "NetworkAcls[*].{ID:NetworkAclId,IsDefault:IsDefault,Subnets:Associations[*].SubnetId, InboundRules:Entries[?!Egress].{Rule:RuleNumber,Action:RuleAction,CIDR:CidrBlock}, OutboundRules:Entries[?Egress].{Rule:RuleNumber,Action:RuleAction,CIDR:CidrBlock}}" \
   --output json
```

HTTP(S)だけ通したい場合は下記のように設定する。  
1024以上はレスポンスパケットを通すために許可しておく必要があるが、1024以上のポートがザルになるので、単体ではC2サーバーなどにアウトバウンド接続される危険性がある。SGで必ず防御する必要がある。

```sh
$ aws ec2 create-network-acl-entry --network-acl-id $PUBLIC_NACL_ID \
  --rule-number 100 --protocol tcp --port-range From=80,To=80 \
  --cidr-block 0.0.0.0/0 --rule-action allow --egress

$ aws ec2 create-network-acl-entry --network-acl-id $PUBLIC_NACL_ID \
  --rule-number 110 --protocol tcp --port-range From=443,To=443 \
  --cidr-block 0.0.0.0/0 --rule-action allow --egress

$ aws ec2 create-network-acl-entry --network-acl-id $PUBLIC_NACL_ID \
  --rule-number 120 --protocol tcp --port-range From=8080,To=8080 \
  --cidr-block 10.0.2.0/24 --rule-action allow --egress

$ aws ec2 create-network-acl-entry --network-acl-id $PUBLIC_NACL_ID \
  --rule-number 200 --protocol tcp --port-range From=1024,To=65535 \
  --cidr-block 0.0.0.0/0 --rule-action allow --egress
```
