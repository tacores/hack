## key vault

https://learn.microsoft.com/ja-jp/cli/azure/keyvault/secret?view=azure-cli-latest

シークレット一覧

```sh
$ az keyvault secret list --vault-name ccabana-kv-f5scjagc --query "[].id" -o tsv

https://ccabana-kv-f5scjagc.vault.azure.net/secrets/key-shard-1
https://ccabana-kv-f5scjagc.vault.azure.net/secrets/key-shard-2
https://ccabana-kv-f5scjagc.vault.azure.net/secrets/key-shard-3
https://ccabana-kv-f5scjagc.vault.azure.net/secrets/master-key
```

全シークレットの全バージョンを一括取得する

```sh
for secret in key1 key2 key3; do echo -e "\n=== Secret: $secret ==="; az keyvault secret list-versions --vault-name ccabana-kv-f5scjagc --name "$secret" --query "[].{id:id, created:attributes.created}" -o json | jq -r '.[] | "\(.created) \(.id)"' | while read -r created id; do val=$(az keyvault secret show --id "$id" --query value -o tsv); echo -e "Created: $created\nValue:   $val\n---"; done; done
```

## TAP (一時アクセスパス)

https://tryhackme.com/room/tapper

アプリケーションに `UserAuthenticationMethod.ReadWrite.All` 権限がついているとする。

アプリケーションのOwnerユーザーとしてログイン。

```sh
az login --username gumby@201618.onmicrosoft.com --allow-no-subscriptions
```

新しいクライアントシークレットを追加。

```sh
az ad app credential reset \
  --id b126c695-541a-4174-b75d-7df2f1607d4b \
  --append \
  --display-name "foobar" \
  --years 1
```

アプリケーションのアプリ専用アクセストークンを取得。

```sh
curl -X POST \
  https://login.microsoftonline.com/a5e3d499-5220-48cf-b044-d2502184fd52/oauth2/v2.0/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "client_id=b126c695-541a-4174-b75d-7df2f1607d4b" \
  -d "client_secret=REDACTED" \
  -d "grant_type=client_credentials" \
  -d "scope=https://graph.microsoft.com/.default"
```

pokey@201618.onmicrosoft.com ユーザーのTAPを作成。→ porta.azure.com からログイン。

```sh
curl -X POST \
  https://graph.microsoft.com/v1.0/users/pokey@201618.onmicrosoft.com/authentication/temporaryAccessPassMethods \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
        "lifetimeInMinutes": 60,
        "isUsableOnce": false
      }'
```
