## 用語

- SSID: 接続しようとしたときに表示されるネットワークの「名前」
- ESSID: 複数のアクセスポイント（例えば、会社のオフィスなど）に適用される可能性のあるSSID。通常は大規模なネットワークを形成する。Aircrackでは、通常、攻撃対象のネットワークを指す。
- BSSID: アクセスポイントのMAC（ハードウェア）アドレス
- WPA2-PSK: 誰でも同じ事前共有パスワードを入力して接続するWi-Fiネットワーク
- WPA2-EAP: ユーザー名とパスワードを入力して認証し、RADIUS サーバーに送信される Wi-Fi ネットワーク。
- RADIUS: Wi-Fi だけでなく、クライアントを認証するためのサーバー。
- ステーション: PCやスマホなど、アクセスポイントに接続するクライアントのこと。
- SSIDクローキング: ビーコンから名前を削除する。それ以上のことは何も行わない。スキャン時、ESSID列に `<length:  9>` のように表示される。

## 802.11フレーム

### フレームクラス

1. 管理フレーム

ステーションとアクセスポイント間の関係を確立および維持する。古い規格では、管理フレームは認証なしで平文で無線を通過するため、通信範囲内のどのデバイスでも読み取ったり偽造したりすることが可能。

2. 制御フレーム

バイスが同時に送信しないように共有メディアへのアクセスを調整する短いメッセージ。RTSおよびCTS(送信要求および送信許可) は送信前にチャネルを予約し、 はACKフレームが破損なく受信されたことを確認する。

3. データフレーム

ネットワークが輸送する目的であるペイロードを運ぶ。暗号化されたネットワークでは、そのペイロードは保護されるが、それを囲むヘッダーは保護されない。

### ビーコンフレーム

アクセスポイントは、ビーコンフレームをブロードキャストすることで自身の存在を通知する。通常、ビーコンフレームは1秒間に約10回送信される。各ビーコンフレームには、アクセスポイントのBSSID、ネットワークがESSIDを非公開に設定していない限りネットワークのESSID、動作チャネル、サポートされているデータレート、および使用されているセキュリティ構成が含まれる。

### プローブ要求

クライアントがネットワークをアクティブに検索する際に送信する管理フレーム。多くの実装では、デバイスが以前接続したことのあるネットワークを名前でプローブするため、電話やラップトップは、信頼できるネットワークのリストを範囲内のすべての受信機にブロードキャストする。プローブされたネットワークをホストするアクセスポイントは、ビーコンとほぼ同じ情報を含むプローブ応答を返す。

### 認証、関連付け、および認証解除

ネットワークへの参加は、管理フレームで行われる2段階のやり取り。まず、ステーションはアクセスポイントで認証を行い、次にアクセスポイントと関連付けを行う。接続の終了には、認証解除フレームという単一のフレームのみが必要で、これはどちらの側からでも送信できる。WPA2では、そのフレームは認証されない。

## モニターモード

### マネージドモード

無線機は通常のクライアントとして動作し、単一のアクセスポイントに接続して、自身宛てのフレームのみをオペレーティングシステムに渡し、それ以外の受信フレームはすべて破棄する。

### モニターモード

モニターモードのインターフェースは、現在のチャネルで受信したすべての802.11フレームを、フレームが属するネットワークやデバイスに関係なく、パッシブにキャプチャする。そのため、ビーコン、プローブ要求、認証ハンドシェイク、通常のデータトラフィックなど、すべてのトラフィックがキャプチャ層に到達する。

#### 干渉プロセスへの対処

```sh
sudo airmon-ng check

# 干渉プロセスを停止
sudo airmon-ng check kill
```

```sh
# モニターモードON
sudo airmon-ng start wlan0

# モード確認
sudo iw dev
```

## スキャン

```sh
# 2.5GHz帯をスキャン。
sudo airodump-ng --band bg wlan0mon

# 5GHz帯をスキャン。
sudo airodump-ng --band a -c 44 wlan0mon

# --band abg はすべてのバンドをスイープする。
```

```sh
# チャネルとBSSIDによるフィルタリング。チャネル44に固定。
sudo airodump-ng -c 44 --bssid F0:9F:C2:71:22:15 -w corpnet-capture wlan0mon
```

`AUTH = MGT` は、エンタープライズ 802.1X 認証のマーカー。

### 攻撃可能な種類

| **値**          | **分類**     | **意味**                                                                |
| -------------- | ---------- | --------------------------------------------------------------------- |
| **OPN**        | ENC        | オープンネットワーク。**暗号化は一切ありません**。                                           |
| **WEP**        | ENC        | 古い方式で、**完全に破られている暗号化方式**です。オープンネットワークとして扱います。                         |
| **WPA2 + PSK** | ENC / AUTH | 「Personal（個人向け）」のWPA2。**全員で1つの共有パスワードを使用**します。典型的なハンドシェイク・キャプチャの対象です。 |
| **WPA3 + SAE** | ENC / AUTH | WPA3-Personal。**SAEハンドシェイク**を使用し、オフラインでのパスワード解析に耐性があります。              |
| **OWE**        | AUTH       | **暗号化されたオープンネットワーク**。パスワードは不要ですが、通信は保護されます。                           |
| **MGT**        | AUTH       | **Enterprise / 802.1X**。ユーザーごとに個別の認証情報を持ち、それを中央の認証サーバーで確認します。         |

### キャプチャのディスク保存

```sh
# キャプチャをディスク保存
sudo airodump-ng --bssid F0:9F:C2:71:22:12 -c 6 -w home2g wlan0mon

ls
home2g-01.cap  home2g-01.csv  home2g-01.kismet.csv  home2g-01.kismet.netxml  home2g-01.log.csv

# 要約のみが必要な場合
sudo airodump-ng --output-format csv --bssid F0:9F:C2:71:22:12 -c 6 -w home2g wlan0mon
```

| **ファイル**             | **内容**                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **`.cap`**           | **生のキャプチャパケット**で、最も重要なファイルです。ビーコンからハンドシェイクまで、無線LANアダプターが受信したすべてのフレームが含まれます。パスワードの復元に `aircrack-ng` へ渡すファイルでもあります。   |
| **`.csv`**           | 観測したすべてのアクセスポイントとクライアントについて、**BSSID、チャンネル、暗号化方式、接続している端末**などをまとめたプレーンテキスト形式の一覧です。`grep` で検索したり、メモに貼り付けたりするのに適しています。 |
| **`.kismet.csv`**    | 同じ調査結果を、**Kismet独自のCSV形式**で保存したものです。ネットワーク情報は同じですが、Kismetの形式に合わせて異なる列名が使用されています。この形式を必要とするツールで利用できます。               |
| **`.kismet.netxml`** | 同じ調査結果を、**KismetのXML形式**で保存したものです。この形式に対応したツールで読み込むことができます。                                                         |
| **`.log.csv`**       | **通信・活動状況の継続的なログ**です。GPSレシーバーが接続されている場合は、GPSデータも含まれます。                                                              |
