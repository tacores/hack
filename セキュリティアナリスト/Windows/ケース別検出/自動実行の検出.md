# 自動実行の検出

https://tryhackme.com/room/detectingpersistentautostartrunkeys

## レジストリ

### AutoStart

- HKCU\Software\Microsoft\Windows\CurrentVersion\Run
- HKLM\Software\Microsoft\Windows\CurrentVersion\Run
- HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce
- HKLM\Software\Microsoft\Windows\CurrentVersion\RunOnce
- HKLM\Software\Microsoft\Windows\CurrentVersion\RunServices

### WinLogon

- HKLM\Software\Microsoft\Windows NT\CurrentVersion\Winlogon\Userinit – ユーザー認証直後に実行されるプログラムを定義。デフォルトでは、userinit.exeが起動され、その後ユーザー環境が起動する。
- HKLM\Software\Microsoft\Windows NT\CurrentVersion\Winlogon\Shell – Windows デスクトップ環境を提供する既定のシェル (通常はexplorer.exe ) を定義。

### Tips

下記のように環境変数を使って設定される場合もあるので見落とさないように注意。
