## アーティファクト

### ライブシステム

```ps
Get-LocalUser | Select-Object Name, Enabled, LastLogon, PasswordLastSet, Description
```

```ps
Get-LocalGroupMember -Group "Administrators" | Select-Object Name, ObjectClass, PrincipalSource
```

```ps
Get-LocalGroupMember -Group "Remote Desktop Users" | Select-Object Name, ObjectClass, PrincipalSource
```

### レジストリハイブ

- SAM: ローカルアカウントとグループ情報が保存
- SYSTEM: ローカルシステム構成を解釈するために必要なコンテキスト情報
- SECURITY: フォレンジック調査の際に、ポリシーやローカルセキュリティに関する有用なコンテキスト情報

### プロファイルリスト

Windowsがユーザープロファイルを作成または読み込むと、C:\Usersフォルダ内およびProfileListレジストリキーに痕跡が残る場合がある。ProfileListキーは、ユーザーSIDをプロファイルパスにマッピングする。

```ps
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList\*" | Select-Object PSChildName, ProfileImagePath
```

### ADユーザーのプロパティ

```ps
Get-ADUser -Identity <アカウント名> -Properties Enabled, whenCreated, whenChanged, PasswordLastSet, LastLogonDate, Description | Select-Object Name, SamAccountName, Enabled, whenCreated, whenChanged, PasswordLastSet, LastLogonDate, Description
```

```ps
# グループ
Get-ADPrincipalGroupMembership <アカウント名> | Select-Object Name, GroupCategory, GroupScope
```

| **調査ステップ** | **調査対象・証跡** | **確認事項** |
| :--- | :--- | :--- |
| ローカルアカウントの確認 | ローカルユーザー、SAMハイブ | 予期しない有効なローカルアカウントが存在するか |
| ローカルグループの確認 | Administrators、Remote Desktop Users | アカウントに特権またはリモートアクセス権が付与されたか |
| プロファイルの確認 | ProfileList、`C:\Users` | そのアカウントがシステム上で使用されたか |
| Active Directoryアカウントの確認 | ADユーザー属性 | ドメインアカウントが作成、有効化、または変更されたか |
| グループメンバーシップの確認 | ADグループ、特権グループ | そのアカウントに有用なアクセス権が付与されたか |
| 時系列の分析 | 複数の証跡を組み合わせて分析 | 一連の変更が永続化のための攻撃経路を形成しているか |
