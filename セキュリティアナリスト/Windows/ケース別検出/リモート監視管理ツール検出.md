# リモート監視管理ツール検出

https://tryhackme.com/room/externalremoteserviceswinir

 AnyDesk、TeamViewer、Atera、ConnectWise ScreenConnectなどなどの、いわゆるRMMツール。

## AnyDesk

| **項目** | **インストールモード** | **ポータブルモード** |
| :--- | :--- | :--- |
| 実行ファイル | `%ProgramFiles%\AnyDesk\` または `%ProgramFiles(x86)%\AnyDesk\` | ユーザーが指定したディレクトリ |
| 設定ファイル | `%ProgramData%\AnyDesk\*.conf` | `%APPDATA%\Roaming\AnyDesk\*.conf` |
| 動作ログ | `%ProgramData%\AnyDesk\ad_svc.trace` | `%APPDATA%\Roaming\AnyDesk\ad.trace` |
| 接続履歴 | `%ProgramData%\AnyDesk\connection_trace.txt` | `%APPDATA%\Roaming\AnyDesk\connection_trace.txt` |

インストールされた場合のサービスレジストリキー

```
HKLM\SYSTEM\CurrentControlSet\Services\AnyDesk
```

```ps
Get-Service AnyDesk -ErrorAction SilentlyContinue

Get-ItemProperty "HKLM:\SYSTEM\CurrentControlSet\Services\AnyDesk" | Select-Object DisplayName, ImagePath, Start

Get-ChildItem "C:\ProgramData\AnyDesk"
```

## TeamViewer

| **調査対象** | **保存場所** | **調査で確認できること** |
| :--- | :--- | :--- |
| インストールディレクトリ | `%ProgramFiles%\TeamViewer\` または `%ProgramFiles(x86)%\TeamViewer\` | インストール版が実行されていることを確認できる |
| レジストリ設定 | `HKLM\SOFTWARE\TeamViewer` | ローカルのTeamViewer IDやインストール情報が含まれている可能性がある |
| サービス | `HKLM\SYSTEM\CurrentControlSet\Services\TeamViewer` | 永続的な自動起動の設定を確認し、サービスの実行ファイルを特定できる |
| インストールログ | `%TEMP%\TeamViewer\TV<version>Install.log` | インストールされたバージョン、ユーザー、インストール日時を特定できる可能性がある |
| 動作ログ | `%ProgramFiles%\TeamViewer\TeamViewer<version>_Logfile.log` | 認証情報、リモートID、アカウント名、IPアドレス、セッション終了、ファイル転送などを確認できる可能性がある |
| ネットワークログ | `%ProgramFiles%\TeamViewer\TVNetwork.log` | TeamViewerのネットワーク通信や中継サーバーとの通信が記録されている |

## Atera

| **調査対象** | **保存場所** | **調査で確認できること** |
| :--- | :--- | :--- |
| インストールディレクトリ | `%ProgramFiles%\Atera Networks\` または `%ProgramFiles(x86)%\Atera Networks\` | インストールされたエージェントの構成要素を確認できる |
| セットアップログ | `%windir%\Temp\AteraSetupLog.txt` | インストール日時、テナントアカウントID、テナントのメールアドレスを特定できる可能性がある |
| サービス | `HKLM\SYSTEM\CurrentControlSet\Services\AteraAgent` | 永続的な自動起動の設定を確認し、エージェントの実行ファイルを特定できる |
| テナント設定 | `HKLM\SOFTWARE\Atera Networks\AlphaAgent` | テナントアカウントIDや関連付けられたメールアドレスが含まれている可能性がある |
| 対話型コマンドログ | `%ProgramFiles%\Atera Networks\AteraAgent\Packages\AgentPackageRunCommandInteractive\log.txt` または `%ProgramFiles%\Atera Networks\AteraAgent\Agent\Packages\AgentPackageRunCommandInteractive\log.txt` | リモートで実行されたコマンド、タイムスタンプ、コマンドの出力が記録されている可能性がある |

## Supremo

| **調査対象** | **保存場所** | **調査で確認できること** |
| :--- | :--- | :--- |
| インストールディレクトリ | `%ProgramFiles(x86)%\Supremo\` | インストールされたSupremoの構成要素を確認できる |
| サービス | `HKLM\SYSTEM\CurrentControlSet\Services\SupremoService` | 無人リモートアクセスが継続的に利用可能な状態かを確認できる |
| サービス実行ファイル | `%ProgramFiles(x86)%\Supremo\SupremoService.exe` | 常駐サービスによって起動される実行ファイルを特定できる |
| メインアプリケーション | `%ProgramFiles(x86)%\Supremo\Supremo.exe` | リモート制御機能を提供する |
| サービスログ | `%ProgramData%\SupremoRemoteDesktop\Log\SupremoService.00.Service.log` | インストールされたサービスの起動時刻を特定できる可能性がある |
| クライアントログ | `%ProgramData%\SupremoRemoteDesktop\Log\Supremo.00.Client.log` | クライアントが使用した中継サーバーの情報を特定できる可能性がある |
| 着信セッションログ | `%ProgramData%\SupremoRemoteDesktop\Log\Supremo.00.Incoming.log` | 着信したリモートセッションに関連付けられたホスト名を特定できる可能性がある |
| セッションレポートログ | `%ProgramData%\SupremoRemoteDesktop\Log\Supremo.00.ReportsQueue.log` | リモートセッションの開始時刻と終了時刻を特定できる可能性がある |
| ファイル転送ログ | `%ProgramData%\SupremoRemoteDesktop\Log\Supremo.00.FileTransfer.log` | ファイルの送信・受信履歴を確認できる |

## Splashtop

| **調査対象** | **保存場所** | **調査で確認できること** |
| :--- | :--- | :--- |
| インストールディレクトリ | `%ProgramFiles(x86)%\Splashtop\`、`%ProgramData%\Splashtop\`、`%LOCALAPPDATA%\Splashtop\` | インストールされた構成要素、設定データ、アプリケーションログを特定できる |
| リモートサービス | `HKLM\SYSTEM\CurrentControlSet\Services\SplashtopRemoteService` | リモートアクセス機能が常駐していることを確認できる |
| ソフトウェア更新サービス | `HKLM\SYSTEM\CurrentControlSet\Services\SSUService` | 常駐するSplashtopの更新コンポーネントを特定できる |
| セッションログ | `%ProgramFiles(x86)%\Splashtop\Splashtop Remote\Server\log\SPLog.txt` | リモートセッション、中継サーバー、アカウント、操作者の情報を特定できる可能性がある |
| ファイル転送ログ | `%ProgramData%\Splashtop\Temp\log\FTCLog.txt` | 転送されたファイル、タイムスタンプ、転送方向、ステータスを特定できる可能性がある |
| リモートクライアント情報 | `HKLM\SOFTWARE\WOW6432Node\Splashtop Inc.\Splashtop Remote Server\ClientInfo` | リモート側のグローバルIPアドレス、アカウント、操作者のホスト名を特定できる可能性がある |

## Remote Utilities

| **調査対象** | **インストール型ホスト** | **ポータブルエージェント** |
| :--- | :--- | :--- |
| 実行ファイル | `%ProgramFiles(x86)%\Remote Utilities - Host\rutserv.exe` | `%APPDATA%\Remote Utilities Agent\<version>\<random>\rutserv.exe` |
| 操作ログ | `%ProgramData%\Remote Utilities\Logs\rut_log_yyyy-mm.html` | `%APPDATA%\Remote Utilities Agent\Logs\rut_log_yyyy-mm.html` |
| レジストリ設定 | `HKLM\SOFTWARE\Usoris\Remote Utilities Host\Host\Parameters` | `HKCU\SOFTWARE\Usoris\Remote Utilities\Host\Parameters` |
| 常駐サービス | `HKLM\SYSTEM\CurrentControlSet\Services\RManService` | 通常は作成されない |
