# スクリプトベース攻撃の検出

https://tryhackme.com/room/scriptexecutionwinir


| 項目 | **VBA** | **VBScript** |
| :--- | :--- | :--- |
| 拡張子 | `.docm`、`.xlsm`、`.pptm`、`.dotm` | `.vbs`、`.vbe`（エンコード済み） |
| 実行環境 | Office アプリケーション（`winword.exe`、`excel.exe`） | Windows Script Host（`wscript.exe` / `cscript.exe`） |
| エントリーポイント | `Document_Open`、`Workbook_Open`、`AutoOpen` （自動実行） | 起動時にスクリプトの先頭から順番に実行 |

| 項目 | **JScript** | **HTA** |
| :--- | :--- | :--- |
| 拡張子 | `.js`、`.jse`（エンコード済み） | `.hta` |
| 実行環境 | Windows Script Host（`wscript.exe` / `cscript.exe`） | `mshta.exe` |
| エントリーポイント | ダブルクリックで実行、または他のアプリケーション経由で呼び出されて実行 | 起動時に埋め込みスクリプトを実行 |

## イベントログ

- Sysmon 7: イメージの読み込み（例：VBE7.DLL）
- Sysmon 1: プロセス生成（例：mshta.exe）
- Security 4688: プロセス生成
- Microsoft-Windows-PowerShell/Operational 4104: スクリプトブロック
- Sysmon 3: ネットワーク接続
- Systemon 12/13: レジストリ作成、更新

### レジストリ

「コンテンツの有効化」を押してマクロを有効にした時、レジストリに記録される。

```sh
.\RECmd.exe -f "C:\Cases\NTUSER.DAT" --kn "Software\Microsoft\Office\16.0\Word\Security\Trusted Documents\TrustRecords"
```

スクリプト実行の結果を確認する例

```sh
.\RECmd.exe -f "C:\Cases\NTUSER.DAT" --kn "Software\Microsoft\Windows\CurrentVersion\Run"
```
