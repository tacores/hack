# 永続性の検出

## スケジュールされたタスクの検出

https://tryhackme.com/room/detectingpersistentscheduledtasks

### イベントログ

| **目的** | **ログソース** | **イベント ID** | **確認できる内容** |
| :--- | :--- | :--- | :--- |
| タスクの作成・変更 | Security | 4698 / 4702 | タスクを作成または変更したユーザー |
| タスクの実行 | TaskScheduler Operational | 100 / 200 / 201 | タスクおよびアクションの実行時系列 |
| プロセスの実行 | Security / Sysmon | 4688 / 1 | `schtasks.exe` / `at.exe` の実行 |
| PowerShell の操作 | PowerShell | 4104 | スクリプトによるタスクの作成 |

### アーティファクト

[Kansa](https://github.com/davehull/Kansa/tree/master)スクリプト

```ps
PS C:\Tools\Kansa>.\Modules\ASEP\Get-SchedTasks.ps1 
```

| **調査目的** | **アーティファクトのソース** | **アーティファクトの場所** | **アーティファクトから判明すること** |
| :--- | :--- | :--- | :--- |
| システム上で永続化に使用されているスケジュールタスクの特定 | ファイルシステム | `C:\Windows\System32\Tasks\` | 再起動後も永続化を維持するために必要な、ディスク上のスケジュールタスク定義ファイル |
| タスクの実行方法と実行タイミングの把握 | スケジュールタスク定義ファイル | `C:\Windows\System32\Tasks\<FullTaskPath>` | トリガー、設定されたアクション、実行頻度、タスクが使用するアカウントコンテキストなどの実行ロジック |
| タスクが Windows に登録されていることの確認 | Windows レジストリ（TaskCache） | `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Schedule\TaskCache` | タスクスケジューラサービスが使用する内部レジストリ情報。タスクの内部識別子やメタデータなどを含む |
| ファイルシステムとレジストリのアーティファクトの相関分析 | ファイルシステムとレジストリの組み合わせ | ディスク上のスケジュールタスクファイルと TaskCache のレジストリエントリ | タスク定義、レジストリのメタデータ、内部識別子が、すべて同じ永続化の仕組みを示していることを確認できる |
| ローカルアクセスなしでのスケジュールタスク関連アーティファクトの収集 | リモート DFIR ツールまたはエンドポイントエージェント | XDR プラットフォーム、Kansa、Velociraptor などの DFIR エージェントによるアーティファクト収集 | イベントログが利用できない場合でも、オフラインでのフォレンジック分析に向けて、スケジュールタスク関連アーティファクトを大規模に収集できる |

### イベントログ（サービス）

| **目的** | **Log Source** | **イベントID** | **確認できる内容** |
| :--- | :--- | :--- | :--- |
| サービスのインストール | System | 7045 | 新しいサービス名、パス、スタートアップの種類、実行アカウント |
| サービスのインストール | Security | 4697 | 監査が有効な場合のサービスのインストール |
| プロセスの実行 | Security / Sysmon | 4688 / 1 | sc.exe、PowerShell、その他のサービス作成ツールの実行 |
| サービスの状態変更 | System | 7035 / 7036 | サービスの制御操作、および実行中・停止状態 |
| スタートアップの種類の変更 | System | 7040 | サービスのスタートアップ設定が自動、手動、無効に変更されたこと |
| レジストリの変更 | Sysmon | 12 / 13 | HKLM\SYSTEM\CurrentControlSet\Services 配下の変更 |
| ペイロードの作成 | Sysmon | 11 | サービス作成前に実行ファイルやスクリプトがディスクに書き込まれたこと |
| PowerShellの操作 | PowerShell | 4104 | New-Service やサービス変更コマンドの実行 |

```ps
# System 7045 – システムにサービスがインストールされました
Get-WinEvent -FilterHashtable @{LogName='System'; Id=7045} |
Select-Object TimeCreated, ProviderName, Id, Message |
Format-List

# Security 4697 – システムにサービスがインストールされました
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4697} |
Select-Object TimeCreated, Id, Message |
Format-List

# Sysmon 13 - レジストリ値セット
Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-Sysmon/Operational'; Id=12,13} |
Where-Object {$_.Message -match 'CurrentControlSet\\Services|ImagePath|ServiceDll|Start'} |
Select-Object TimeCreated, Id, Message |
Format-List
```

```ps
# サービス作成変更に関するクエリ
Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-Sysmon/Operational'; Id=1} |
Where-Object {$_.Message -match 'sc.exe|New-Service|WinUpdateSvc|services.exe|update.exe'} |
Select-Object TimeCreated, Id, Message |
Format-List

# Powershellのスクリプトブロックをクエリ
Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-PowerShell/Operational'; Id=4104} |
Where-Object {$_.Message -match 'New-Service|Set-Service|sc.exe|WinUpdateSvc'} |
Select-Object TimeCreated, Id, Message |
Format-List
```
