## よく悪用されるバイナリ

| カテゴリ                     | LOLBin                                | 正規の用途                                                             | 代表的な悪用例                                                                   |
| ------------------------ | --------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------- |
| ソフトウェアのインストールと展開         | `installutil.exe`、`msiexec.exe`、`msbuild.exe`             | ソフトウェアやサービスのインストール、設定、展開                                          | 悪意のあるコードの実行、アプリケーション制御ポリシーの回避、マルウェアの展開                                    |
| システムの設定と管理               | `reg.exe`、`esentutl.exe`、`driverquery.exe`                | レジストリデータベースの操作、OS標準データベースの修復、デバイスドライバーの一覧表示                       | セキュリティ設定の変更によるウイルス対策機能の無効化、ロックされたデータベース（`NTDS.dit`）の強制コピー、稼働中のEDRドライバーの調査 |
| タスクの自動化とスクリプト実行          | `wscript.exe`、`cscript.exe`、`forfiles.exe`、`schtasks.exe` | 管理タスクの自動化、スクリプトの実行、ファイルの管理                                        | 悪意のあるスクリプトやコマンドによるペイロードのダウンロード、永続化、各種操作の実行                                |
| ネットワーク接続とファイル転送          | `bitsadmin.exe`、`ftp.exe`、`hh.exe`、`certutil.exe`         | ファイルの転送、リモートリソースの取得                                               | マルウェアのダウンロード、リモートシステムからの追加ペイロードの取得、攻撃者が用意したコンテンツへのアクセス                    |
| コンポーネントの登録とアプリケーションのサポート | `rundll32.exe`、`regsvr32.exe`、`mshta.exe`、`wmic.exe`      | Windowsコンポーネントの実行、アプリケーションライブラリの登録、アプリケーション支援ファイルの起動、WMIオブジェクトの操作 | 信頼されたWindowsバイナリを介した悪意のあるコードの実行と検知回避                                      |

## よく悪用されるファイルレス技術

| カテゴリ        | 主な手法                                   | 仕組み                                      |
| ----------- | -------------------------------------- | ---------------------------------------- |
| スクリプトベース    | PowerShell、VBScript、JavaScript         | スクリプトエンジンを使用し、悪意のあるコードをすべてメモリ上で実行する      |
| レジストリベース    | Windowsレジストリへのペイロードの保存                 | ファイルではなくレジストリキーにコードを隠し、そこから実行する          |
| メモリインジェクション | リフレクティブDLL、シェルコード、プロセスホロウイング           | 正規のプロセスのメモリにマルウェアを直接読み込み、実行する            |
| LOLBinの悪用   | バイナリの実行（`mshta`、`rundll32`、`regsvr32`） | 信頼されたWindowsツールを利用して、悪意のあるスクリプトやコードを起動する |
| ドキュメントベース   | VBAマクロ、HTAファイル                         | Office文書やリモートのHTMLアプリケーションからコードを実行する     |
