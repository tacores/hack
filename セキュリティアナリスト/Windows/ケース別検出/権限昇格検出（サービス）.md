## 基礎

サービス制御マネージャ（SCM）はすべてのサービスを下記レジストリで管理する。

`HKLM\SYSTEM\CurrentControlSet\Services\<ServiceName>`

| **Registry Value** | **What It Controls**                 | **Why Attackers Care**                   |
| :----------------- | :----------------------------------- | :--------------------------------------- |
| `ImagePath`        | サービス起動時に実行されるバイナリ  | 悪意のあるバイナリに実行先を変更できる  |
| `ServiceDll`       | svchost がホストするサービスが読み込む DLL | 悪意のある DLL を読み込ませることができる |
| `ObjectName`       | サービスの実行アカウント             | `LocalSystem` によりローカルの完全な特権を取得できる |
| `Start`            | サービスの起動タイミング（自動、手動、無効） | 自動に設定すると再起動後も永続化できる |

```ps
# 現在のユーザーが再構成できるすべてのサービスを一覧表示
accesschk.exe -uwcqv "j.rivera" *

# 書き込み可能なサービスに書き込む
sc.exe config OrbitRemote binPath= "C:\Windows\Temp\payload.exe" start= auto
```

```ps
# 現在のユーザーが変更できるレジストリキーを検出
accesschk.exe -kvuqsw "j.rivera" hklm\System\CurrentControlSet\Services

# 変更
reg add "HKLM\SYSTEM\CurrentControlSet\Services\OrbitRemote" /v ImagePath /t REG_EXPAND_SZ /d "C:\Windows\Temp\payload.exe" /f
```

## イベントログ

### 列挙の検出

sc.exe, wmic.exe, winPEAS.exe 等の実行。

### 再構成の検出

| **Attacker Action**                                  | **Fires**                                      |
| :--------------------------------------------------- | :--------------------------------------------- |
| `sc config svc start= auto` (start type)             | System `7040` （既存のWindowsサービスのスタートアップの種類（自動・手動・無効など）が変更された）が発生                            |
| `reg add ...\Services\svc\ImagePath` (registry edit) | Sysmon `13` が発生                              |
| `sc config svc binPath=` (binary path)               | `7040` は発生しない。`ImagePath` への書き込みは Sysmon `13` として記録される可能性がある |

### バイナリ上書き、配置の検出

- 既存バイナリに対するファイル作成イベント（Sysmon 11）
- オブジェクトアクセス（Security 4663）

ペイロードがサービス用にビルドされていない場合、起動時に下記のエラーが記録される。（実行自体はされる）

- System 7000 ("failed to start")
- 7009 ("a timeout was reached while waiting for the service to connect")

| **Phase**    | **Attacker Action**                          | **Detection**                         | **Event IDs**                  |
| :----------- | :------------------------------------------- | :------------------------------------ | :----------------------------- |
| Enumeration  | Manual `wmic`/`sc.exe`                       | プロセス作成（標準ユーザー）           | Sysmon `1`                     |
| Enumeration  | Automated tooling                            | ディスク上のファイル、スクリプトブロック | Sysmon `11`, PowerShell `4104` |
| Reconfigure  | `sc config start= auto`                      | 起動タイプの変更                       | System `7040`                  |
| Reconfigure  | `reg add` ImagePath                          | レジストリ値の設定                     | Sysmon `13`                    |
| Delivery     | Binary overwrite / rogue drop                | サービスパスへの書き込み               | Sysmon `11`, Security `4663`   |
| Trigger      | Service start (payload isn't a real service) | 起動タイムアウト                       | System `7000`, `7009`          |
| Confirmation | Payload runs as SYSTEM                       | `services.exe` が SYSTEM 権限で子プロセスを生成 | Sysmon `1`, Security `4688` |

## アーティファクト

### レジストリ

`HKLM\SYSTEM\CurrentControlSet\Services\<ServiceName>` を調査

#### アクセス権限の調査

1. レジストリエディタで `HKLM\SYSTEM\CurrentControlSet\Services\<ServiceName>\Security` を選択して右クリック
2. Export -> Value data、sd.bin として保存
3. 下記実行

```ps
$bytes = [IO.File]::ReadAllBytes('C:\Users\DFIRUser\sd.bin')
$sd = New-Object System.Security.AccessControl.RawSecurityDescriptor($bytes, 0)
$sd.GetSddlForm('All')   # an ACE granting a standard-user SID the DC (SERVICE_CHANGE_CONFIG) right

# 下記のような出力になる。AIに解読してもらうのが一番速い。
O:SYG:SYD:(A;;CCLCSWRPWPDTLOCRRC;;;SY)(A;;CCDCLCSWRPWPDTLOCRSDRCWDWO;;;BA)(A;;CCLCSWLOCRRC;;;IU)(A;;CCLCSWLOCRRC;;;SU)(A;;CCDCLCSWRPWPDTLOCRRC;;;S-1-5-21-3830996098-2815122620-3244676272-1003)S:(AU;FA;CCDCLCSWRPWPDTLOCRSDRCWDWO;;;WD)
```
