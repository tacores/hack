# スケジュールされたタスクの検出

https://tryhackme.com/room/detectingpersistentscheduledtasks

## イベントログ

| **目的** | **ログソース** | **イベント ID** | **確認できる内容** |
| :--- | :--- | :--- | :--- |
| タスクの作成・変更 | Security | 4698 / 4702 | タスクを作成または変更したユーザー |
| タスクの実行 | TaskScheduler Operational | 100 / 200 / 201 | タスクおよびアクションの実行時系列 |
| プロセスの実行 | Security / Sysmon | 4688 / 1 | `schtasks.exe` / `at.exe` の実行 |
| PowerShell の操作 | PowerShell | 4104 | スクリプトによるタスクの作成 |

## アーティファクト

[Kansa](https://github.com/davehull/Kansa/tree/master)スクリプト

```ps
PS C:\Tools\Kansa>.\Modules\ASEP\Get-SchedTasks.ps1 
```

| **調査目的** | **アーティファクトのソース** | **アーティファクトの場所** | **アーティファクトから判明すること** |
| :--- | :--- | :--- | :--- |
| システム上で永続化に使用されているスケジュールタスクの特定 | ファイルシステム | `C:\Windows\System32\Tasks\` | 再起動後も永続化を維持するために必要な、ディスク上のスケジュールタスク定義ファイル |
| タスクの実行方法と実行タイミングの把握 | スケジュールタスク定義ファイル | `C:\Windows\System32\Tasks\<FullTaskPath>` | トリガー、設定されたアクション、実行頻度、タスクが使用するアカウントコンテキストなどの実行ロジック |
| タスクが Windows に登録されていることの確認 | Windows レジストリ（TaskCache） | `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Schedule\TaskCache` | タスクスケジューラサービスが使用する内部レジストリ情報。タスクの内部識別子やメタデータなどを含む |
| ファイルシステムとレジストリのアーティファクトの相関分析 | ファイルシステムとレジストリの組み合わせ | ディスク上のスケジュールタスクファイルと TaskCache のレジストリエントリ | タスク定義、レジストリのメタデータ、内部識別子が、すべて同じ永続化の仕組みを示していることを確認できる |
| ローカルアクセスなしでのスケジュールタスク関連アーティファクトの収集 | リモート DFIR ツールまたはエンドポイントエージェント | XDR プラットフォーム、Kansa、Velociraptor などの DFIR エージェントによるアーティファクト収集 | イベントログが利用できない場合でも、オフラインでのフォレンジック分析に向けて、スケジュールタスク関連アーティファクトを大規模に収集できる |
