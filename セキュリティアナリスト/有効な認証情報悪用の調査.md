# 有効な認証情報悪用の調査

https://tryhackme.com/room/investigatingvalidcredentialsabuse

## VPN 認証

### RADIUS 認証

#### Securityイベント

- DC による認証情報の検証（4776）
- NPS (Network Policy Server) によるVPNアクセスの許可（6272）
- セッション作成、確立（4624）

6272にはIPアドレスが含まれる。

#### NPS のテキストログ

`C:\Windows\System32\LogFiles\INYYMM.log`

ユーザーIP、サーバーIP、VPN割り当てIP（Frame-IP-Address）等が1行に記録される。

### LDAP 認証

- VPNゲートウェイログ：公開ソースIP、ユーザー名、タイムスタンプ、成功/失敗、および位置情報テレメトリの主要な情報源。
- サーバーSecurityログ：イベントID 4776「認証情報の検証」と、関連するイベントID 4624（ログオンタイプ3（ネットワーク））。

## Windows 認証（RDP）

- Event 4624 (Logon Type 10) : Windows は管理者アカウント用に新しいログオンセッションを作成する。
- Terminal Services Remote Event 1149：RDPサービスは、攻撃者のIPアドレスからの認証が成功したことを記録する。
- Terminal Services Local Event 21：サーバー上のローカルセッションマネージャがリモートデスクトップセッションを終了してアクティブ化する。

## アーティファクト

### SOFTWARE

`HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList`

すべてのセキュリティ識別子（SID）をディスク上のユーザープロファイルにマッピングする。ProfileListは、システムのチェックインログと考えることができる。

### NTUSER

`C:\Users\Administrator\NTUSER.DAT`

ユーザーがログインすると、システムはこのファイルをHKEY_CURRENT_USER(HKCU) レジストリ ハイブとしてマウントする。最終更新時刻が書き換わる。
