# ライブ検出

https://tryhackme.com/room/livedetectionwithlokiandthor

Yara.mdも参照。

## 基本

### トレードオフ

- 攻撃者に情報を漏らす：システムを監視している攻撃者は、防御ツールが実行されていることに気づき、それに応じてツールを変更または削除する可能性がある。
- 揮発性証拠の改ざん：稼働中のシステムを調査する行為は、メモリ、プロセス状態、またはファイルタイムスタンプを変更し、証拠に影響を与える可能性がある。
- 不完全な可視性：ライブスキャンでは、現在実行中のもの、またはディスク上に存在するものしか検出できない。削除されたファイル、過去のアクティビティ、スキャン開始前に存在していたアーティファクトは復元されない。

### LOKI と THOR Lite の違い

| **機能** | **LOKI** | **THOR Lite** |
| :--- | :--- | :--- |
| OSサポート | Windows（WMIによるプロセススキャン、PE-Sieveを含む）、Linux、macOS | Windows（32/64ビット）、Linux（32/64ビット）、macOS（64ビット）。3つのOS向けにコンパイル済みバイナリを提供 |
| ソースコード | GPLv3ライセンスのオープンソース | オープンソースではない。コンパイル済みバイナリ |
| 言語とビルド方式 | Python、Rust | Go |
| ルールセット | シグネチャベースのリポジトリ、公開YARAルール、IOCリスト | 同じオープンソースのシグネチャベースを暗号化して使用（ルール自体がウイルス対策ソフトによって誤検知されるのを防止） |
| モジュールの対応範囲 | Filescan、ProcessCheck、ProcessConnections | Filescan、ProcessCheck、ProcessConnections、Autoruns、LogScan |
| リソース制御 | 組み込みの処理負荷制限機能なし | CPU使用率を制限し、稼働中のシステムへのスキャンの影響を軽減 |
| 出力形式 | コンソール出力、テキストログ、Syslog | コンソール出力、テキストログ、Syslog、JSON、HTMLレポート |

## LOKI

https://github.com/Neo23x0/Loki-RS

LOKIはポータブルでエージェントレスのバイナリなので、セットアップに時間は一切かからず、インストールやインフラストラクチャも不要。USBドライブからでもネットワーク共有からでも実行でき、数分で潜在的な脅威を特定するスコア付きレポートが得られる。

### 使用方法

#### コマンドラインオプション

https://github.com/Neo23x0/Loki#usage

#### 構文例

```sh
.\loki.exe # run a full file system and process scan
.\loki.exe -p C:\Path\To\Directory # scan a specific directory
.\loki.exe --alldrives --scriptanalysis # scan all drives and analyze scripts to detect obfuscated code
```

## THOR

THOR は YARA ルールを暗号化された形式で提供するため、生の検出文字列がマシン上に平文で保存されることはなく、LOKI が引き起こす可能性のあるアンチウイルスの誤検出を回避するのに役立つ。

| **機能** | **THOR APT Scanner** | **THOR Lite** |
| :--- | :--- | :--- |
| シグネチャベース | VALHALLAの非公開シグネチャセット。3万以上のYARAルール、4,000以上のSigmaルール、1万件以上のIOC／パターンエントリを含む | 暗号化された形式のオープンソースシグネチャベース |
| 検知モジュール | Eventlog、RegistryChecks、SHIMCache、DNSCacheなど、30種類のモジュール | Filescan、ProcessCheck、Autorunsなど、5種類のモジュール |
| スキャンモード | ラボスキャンモード、ドロップゾーン監視、複数ホストに対するリモートスキャン | 標準モード（Quick、Soft、Intenseの各バリエーション） |
| 主な用途 | トリアージ、予防的スキャン、インシデント対応、ライブフォレンジック | トリアージ |

### 使用方法

#### 構文例

コマンドライン出力だけでなく、カレントディレクトリにHTMLレポートやCSVも出力される。

```sh
.\thor64-lite.exe # run a full file, process, connection, autorun, and log scan
.\thor64-lite.exe -p C:\Path\To\Directory # scan a specific directory
.\thor64-lite.exe --quick --cpulimit 50 # run a quick scan and pause THOR when CPU usage exceeds 50%
.\thor64-lite.exe -p C:\inetpub -p C:\Windows\Temp -p C:\Users\Public -p C:\Users\svc-webapp
```
